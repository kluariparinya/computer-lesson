Processing

CPU

จอมบงการผู้ปราดเปรื่อง คิดเลขเร็วเป็นล้านครั้งใน 1 วินาที!

คลิกดูความลับ
Memory

RAM

พื้นที่ทำงานชั่วคราว ยิ่งเยอะ เครื่องยิ่งลื่น ไม่สะดุด

คลิกดูความลับ
Storage

SSD / Hard Disk

คลังเก็บความทรงจำถาวร เก็บรูปและเกมได้เป็นหมื่นๆ รูป

คลิกดูความลับ
Main Circuit

Motherboard

บ้านหลังใหญ่ของอุปกรณ์ทุกชิ้น เป็นตัวประสานงานหลัก

คลิกดูความลับ
Graphic

VGA Card

สร้างโลกเสมือนให้สวยงาม ภาพสมจริงต้องยกให้ชิ้นนี้

คลิกดูความลับ
Energy

Power Supply

โรงไฟฟ้าส่วนตัวของคอมพิวเตอร์ ผู้ให้พลังงานแก่ทุกคน

คลิกดูความลับ

📥 การรับข้อมูล และ 📤 การแสดงผล

คอมพิวเตอร์คุยกับเราผ่านอุปกรณ์เหล่านี้นะ!

Input (หน่วยรับเข้า)

คืออุปกรณ์ที่ใช้ "ส่งคำสั่ง" หรือ "ส่งข้อมูล" เข้าไปในเครื่องคอมพิวเตอร์

Keyboard (แผงพิมพ์)

ใช้พิมพ์ตัวอักษรและสั่งงาน

Mouse (เมาส์)

ใช้คลิกเลือกสิ่งต่างๆ บนจอ

Microphone (ไมโครโฟน)

ใช้รับเสียงพูดของเราเข้าไป

Output (หน่วยส่งออก)

คืออุปกรณ์ที่ใช้ "แสดงผล" สิ่งที่คอมพิวเตอร์คิดออกมาให้เราเห็นหรือได้ยิน

Monitor (หน้าจอ)

โชว์รูปภาพและวิดีโอสวยๆ

Speaker (ลำโพง)

ส่งเสียงเพลงและเสียงเกมออกมา

Printer (เครื่องพิมพ์)

พิมพ์รูปหรือการบ้านออกมาบนกระดาษ
